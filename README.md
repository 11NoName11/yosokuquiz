# 🎌 Yosoku Quiz

**Yosoku Quiz** adalah website latihan soal bahasa Jepang untuk membantu belajar dan mempersiapkan diri menghadapi materi **養殖業 (ようしょくぎょう / budidaya perikanan)**.

Quiz dibuat dalam format **〇 (Maru / benar)** dan **× (Batsu / salah)** agar latihan terasa lebih sederhana dan cepat.

## 🌐 Demo

👉 **[yosokuquiz.vercel.app](https://yosokuquiz.vercel.app/)**

## ✨ Features

* 🎯 **Form A** — latihan soal pilihan/kuis
* 🔴 **Form B** — latihan soal 〇 / ×
* 📚 Materi seputar **養殖 (ようしょく)**
* 🇯🇵 Soal menggunakan bahasa Jepang
* 📱 Responsive untuk desktop dan mobile
* ⚡ Tidak membutuhkan backend
* 🌐 Bisa dijalankan langsung melalui browser

## 📖 Materi

Beberapa materi yang terdapat dalam quiz:

* 養殖業 — Budidaya perikanan
* 魚類養殖 — Budidaya ikan
* ほたてがい — Kerang scallop
* まがき — Tiram
* 養殖魚の管理
* Penyakit ikan
* Kualitas air
* Pakan ikan
* Lingkungan budidaya
* Keselamatan kerja dalam budidaya

## 🚀 Run Locally

Clone repository:

```bash
git clone https://github.com/11NoName11/yosokuquiz.git
```

Masuk ke folder project:

```bash
cd yosokuquiz
```

Kemudian buka:

```text
index.html
```

di browser.

Tidak membutuhkan `npm install` atau server backend.

## 📱 Usage

1. Buka halaman utama.
2. Pilih **Form A** atau **Form B**.
3. Kerjakan soal satu per satu.
4. Periksa hasil jawaban.
5. Ulangi latihan untuk meningkatkan pemahaman.

## 🎯 Purpose

Project ini dibuat sebagai media latihan pribadi untuk mempermudah proses belajar dan mengulang materi sebelum menghadapi ujian/tes terkait **養殖業**.

Project ini juga menjadi salah satu latihan dalam pengembangan website menggunakan HTML, CSS, dan JavaScript.
